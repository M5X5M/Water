# غابة (ForestGlass)
تطبيق أندرويد لطلاب السادس علمي: زجاج مائي تفاعلي، فيديوهات المدرسين فقط، ووضع تركيز مقفل بمخرج طوارئ.
تشغيل: Kotlin + Jetpack Compose. يدعم الهواتف والتابلت (تخطيط يتوسع عند عرض 600dp فأكثر).

## البناء بدون لابتوب
1. أنشئ مستودعاً على GitHub وارفع كل الملفات (مجلد .github مهم).
2. افتح تبويب Actions ← Build APK ← Run workflow.
3. بعد دقائق حمّل ملف APK من Artifacts وثبّته على جوالك.

## الخلفية الحقيقية
استبدل app/src/main/res/drawable-nodpi/forest.jpg بصورة غابة خضراء حقيقية بدقة عالية (طولية 1080×2340 أو أكبر).

## قبل النشر
- ضع معرفات فيديوهات يوتيوب الحقيقية في LESSONS (Screens.kt).
- غيّر EMERGENCY_PIN.
- التأثير المائي (AGSL) يعمل على أندرويد 13 فأعلى، وما دونه يعرض زجاجاً هادئاً بلا تشويه.
